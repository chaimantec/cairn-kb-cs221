# See also — related knowledge bases

Other Cairn knowledge bases whose material genuinely bears on this course. Each entry says what
that KB is good for, so it is worth deciding *before* spending a fetch on it. Links point at
`raw.githubusercontent.com` because that returns plain markdown; a `github.com/.../blob/...` URL
returns a rendered HTML page instead.

- **CS224N — Natural Language Processing with Deep Learning** (Stanford, Christopher Manning,
  Spring 2024). Where the neural machinery in lectures 2–4 of this course gets applied to language
  and taken much further: word vectors, RNNs and LSTMs, attention and Transformers, pretraining
  and post-training of large language models, and evaluation. Reach for it when a CS221 question
  runs past the foundations — anything about sequence models, attention, tokenization or LLMs is
  covered there in depth and not here. **Complete: all 23 lectures**, with slide-by-slide text for
  every deck.
